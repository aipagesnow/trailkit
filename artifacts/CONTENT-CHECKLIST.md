# New page checklist

Use this for every commercial page before it is indexed.

## Search

- [ ] Primary keyword is a commercial or commercial-investigation query (best, vs, under $X, for [constraint])
- [ ] Title starts with the primary keyword and stays under ~60 characters
- [ ] Meta description is unique, includes the constraint, and stays under ~155 characters
- [ ] One H1, then H2s for comparison, picks, single recommendation, FAQ
- [ ] URL matches `/best/`, `/compare/`, `/guides/`, or `/gear/`
- [ ] Canonical is absolute and matches the live domain
- [ ] Page added to `sitemap.xml` and linked from a hub

## Answer

- [ ] Direct answer in the first 100 words
- [ ] “Who this is for” names who should skip the page
- [ ] Comparison table: price range, weight, best for, standout limitation
- [ ] No hard-coded live prices. “Check current price” only
- [ ] 4–7 product sections with pros, cons, who should buy, Amazon button
- [ ] “If you only buy one” recommendation
- [ ] 3–6 FAQs
- [ ] Methodology note and updated date
- [ ] Illustrative models labeled illustrative

## Affiliate

- [ ] Tag comes from `js/site.js` / `site.config.json`, not a one-off string
- [ ] Links are `class="amz"` and `rel="sponsored nofollow"`
- [ ] Disclosure visible before the first product button
- [ ] Footer disclosure still present

## Links and schema

- [ ] At least two descriptive internal links to other guides
- [ ] Related module filled
- [ ] Article, BreadcrumbList, FAQPage, and ItemList/Product JSON-LD still valid
- [ ] Images, if added, have descriptive alt text and width/height or a reserved box (CLS)

## Launch

- [ ] Mobile: table scrolls, TOC is not covering text, buttons are tappable
- [ ] Amazon link opens the right product
- [ ] No popup
