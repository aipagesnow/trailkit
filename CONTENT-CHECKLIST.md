# Trailkit content checklist

Use this before publishing a money page. Voice stays clear and constraint-first. Do not invent a trail test.

- [ ] Unique title and meta description. Absolute canonical comes from the route helper.
- [ ] Direct answer in the first screen, then a “who this is for” line.
- [ ] Comparison table uses price **bands**, not a hard-coded dollar price.
- [ ] 4–7 picks. Each has a role, who should buy it, pros, cons, and a limitation.
- [ ] Number 1 is the default pick. “If you only buy one” names that pick and the person who should skip it.
- [ ] FAQ answers the real objections (width, weather, weight, budget).
- [ ] Slim disclosure strip is on the page and links to `/disclosure`.
- [ ] Related links point at a guide, a comparison, or another roundup — not a dead hub.
- [ ] Updated date is visible.
- [ ] Amazon button is **See on Amazon** only when `src/data/asins.ts` has a verified US ASIN. Otherwise leave the “not verified” line. Never paste a search URL or `yourtag-20`.
- [ ] No star scores, no fake lab ratings, no “we hiked this last weekend” unless a real test is documented.
- [ ] Hero image, if any, is a desaturated in-use trail photo with width and height set. No logo lockups inside the photo. No Amazon packshot scrape.
